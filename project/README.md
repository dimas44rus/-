# 📚 Менеджер учебных задач

Небольшое веб-приложение для планирования и отслеживания учебных задач.
Работает полностью в браузере, без сервера и регистрации. Все данные
хранятся локально на устройстве пользователя.

**Версия:** 2.0 · **Стек:** HTML5 · CSS3 · JavaScript (ES6+)

---

## ✨ Возможности

### Управление задачами
- ➕ Добавление задач с названием, описанием, приоритетом и сроком
- ✏️ Редактирование любой задачи
- ✅ Отметка задачи как выполненной
- 🗑️ Удаление с подтверждением
- 🧹 Массовая очистка выполненных задач

### Организация
- 🔍 Полнотекстовый поиск по названию и описанию
- 🎯 Фильтры: все / активные / выполненные / высокий приоритет
- 🔄 Сортировка: по добавлению / сроку / приоритету
- 🔢 Счётчики задач в каждом фильтре

### Наглядность
- 📊 Статистика: всего / выполнено / в процессе
- 📈 Прогресс-бар выполнения
- 🔥 Автоматический бейдж «Срочно» для горящих дедлайнов
- ⏰ Подсветка просроченных и близких сроков

### Комфорт
- 🌙 Тёмная тема (автоопределение + ручной переключатель)
- 💾 Автосохранение в `localStorage`
- 📤 Экспорт и 📥 импорт задач в формате JSON
- ⌨️ Горячие клавиши: `/` — поиск, `Esc` — отмена редактирования
- 📱 Адаптивный интерфейс для телефонов и планшетов
